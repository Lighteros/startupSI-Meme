# startupSI-Meme

Static mirror of [startupsi.fun](https://www.startupsi.fun/) for **startupsi.org**, with live API data proxied from the upstream launchpad.

- **X:** [@startupsipad](https://x.com/startupsipad)
- **CA:** configured in `assets/site-config.js` (`PUMP_MINT`)

## Deploy

Hosted on Vercel. Clean URLs and `/api/*` proxy are defined in `vercel.json`.
